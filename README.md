# PRD template

A product requirements document template in Markdown: problem, target user,
must / should / could / won't features with a reason each, success metrics,
non-goals, risks and open questions.

- `PRD.md`: the template. Guidance sits in HTML comments, which GitHub hides.
- `examples/awas-prd.md`: a filled example, the PRD from a real Murmur run
  (Awas), published with the owner's permission.

Use it: click "Use this template", or copy PRD.md into your repo.
